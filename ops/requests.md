「① 제작」 예약 작업이 `- [ ]` 줄이 있을 때만 켜져서 만들고 배포한다(줄이 없으면 Opus를 안 씀).

## 넣는 법
- 채팅·예약 작업: 이 파일 「목록」 맨 아래에 한 줄 → `git commit -m "ops: request <ID>"` → main에 push(이 파일만 바꾸는 커밋은 검사·버전 증가 없이 올려도 됨). 거절되면 `git pull --rebase` 후 다시.
- 형식: `- [ ] **R-MMDD-<채팅>-<짧은이름>** (요청 ⑥ 11-25 10:20) 무엇을·왜 — 참고 문서 · 테스트할 것 · 결과 적을 곳`
- 급하면 이름 앞에 🔴. 한 줄에 하나. 크면 설계 문서 경로만.
- 데이터(presets·slang)·그림(cat/*.svg)만 바뀌는 일은 여기 말고 PR로.

## 상태 표시 (① 제작이 바꿈)
`[~] MM-DD HH:MM 시작` · `[x] vNNN — 결과 · ▶ 이어서 할 것` · `[ ] (이어서: …)` · `[?] 이유 · 필요한 것`
