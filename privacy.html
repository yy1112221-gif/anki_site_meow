개인정보처리방침

시행일: 2026년 11월 19일 (로그인 추가로 개정)

MEOWCA! 암기냥이(이하 "서비스")는 회원가입 없이도 쓰는 단어 암기 웹앱입니다. 로그인은 선택이며, 서비스는 필요한 최소한의 정보만 아래와 같이 처리합니다.

1. 내 기기에 저장되는 정보

  • 추가한 단어, 학습 기록, 설정, 냥이 간식 정보는 이용자의 브라우저(localStorage)에만 저장됩니다.
  • 브라우저 데이터를 지우면 함께 삭제됩니다. 서비스 운영자는 이 정보를 볼 수 없습니다.
  • 문의 냥이: 문의를 보내거나 앱 오류가 나면, 적은 내용과 함께 앱 버전·브라우저 종류·화면 크기·최근 오류 메시지·방금 푼 문제 3개가 운영자 서버(Supabase)로 전송됩니다. 단어장 전체나 이름·이메일 같은 개인정보는 보내지 않습니다. 문의 내용은 답변을 위해 AI(Anthropic Claude)로 분류될 수 있고, 90일 뒤 삭제합니다.
  • 사용 기록(익명): 앱을 더 좋게 만들기 위해, 기기마다 무작위로 만든 번호와 함께 앱 사용 기록(연 화면, 문제 정답 여부, 첫 설정에 걸린 시간, 화면 크기, 태어난 해 등)을 운영자 서버로 보냅니다. 이름·이메일·단어장 내용은 보내지 않고, 400일 뒤 삭제합니다. 「원리·설정」 맨 아래에서 언제든 끌 수 있습니다.
  • 태어난 해: 첫 설정에서 고르면 기기 안과 사용 기록에만 쓰입니다. 건너뛸 수 있습니다.

2. 기기 간 동기화(선택)

  • '동기화 코드'를 직접 켠 경우에만, 학습 데이터(단어·학습 기록·설정)가 클라우드 데이터베이스(Supabase)에 저장됩니다.
  • 동기화 코드 자체는 저장하지 않고, 코드를 일방향으로 변환한 값으로만 데이터를 구분합니다. 코드를 아는 사람만 데이터를 불러올 수 있으니 코드를 다른 사람에게 알려 주지 마세요.
  • 설정에서 동기화를 끄면 더 이상 업로드되지 않습니다. 저장된 데이터 삭제를 원하면 아래 문의처로 요청해 주세요.

3. 로그인(선택)

  • 구글·카카오·LINE으로 로그인하면, 각 회사가 제공하는 고유 식별자, 이메일 주소(제공되는 경우), 이름 또는 닉네임, 프로필 사진 주소가 인증 서버(Supabase)에 저장됩니다. 비밀번호는 받지 않습니다.
  • 목적: 여러 기기에서 같은 학습 기록을 이어 쓰기 위한 계정 확인과 기록 연결. 다른 목적(광고·마케팅)에는 쓰지 않습니다.
  • 보관: 계정 삭제를 요청하면 지체 없이 삭제합니다. 로그인하지 않으면 이 정보는 생기지 않습니다.
  • 만 14세 미만으로 보이는 경우(첫 설정의 태어난 해 기준) 로그인 버튼을 표시하지 않으며, 동기화 코드로만 기록을 옮길 수 있습니다.

4. 외부 서비스로 보내는 정보

  • 번역·예문 조회: 단어 뜻이나 예문을 찾을 때, 그 단어(또는 문장)가 MyMemory 번역 API, Tatoeba, Wiktionary로 전송됩니다.
  • 이메일(선택): 설정에 이메일을 직접 입력한 경우, 번역 사용 한도를 늘리기 위해 그 이메일이 MyMemory 번역 API로 함께 전송됩니다. 입력하지 않으면 전송되지 않습니다.
  • 음성: 발음 듣기는 기기에 내장된 음성 합성 기능을 사용합니다.
  • 호스팅·글꼴: 서비스는 Cloudflare Pages(meowca.app)와 GitHub Pages에서 제공되고 Google Fonts 글꼴을 불러옵니다. 이 과정에서 각 업체가 일반적인 접속 기록(IP 주소 등)을 처리할 수 있습니다.

5. 처리 위탁·국외 이전

서비스 운영을 위해 아래 업체의 클라우드를 이용하며, 정보가 해외(주로 미국) 서버에 저장·처리될 수 있습니다. 이전은 서비스 이용 시 네트워크로 이루어집니다.

  • Supabase Inc.(미국): 동기화 데이터, 로그인 정보, 문의, 익명 사용 기록 저장 — 위 각 항목의 보관 기간까지
  • Telegram(운영자 알림): 문의 내용과 진단 정보를 운영자에게 알리기 위해 전달 — 운영자 대화방에 남음
  • Anthropic PBC(미국, 사용 시): 문의 분류·답변 초안 작성 — 처리 후 서비스가 따로 보관하지 않음
  • Cloudflare Inc.·GitHub Inc.(미국): 웹사이트 호스팅 — 일반 접속 기록

국외 이전을 원하지 않으면 로그인·동기화·문의를 사용하지 않고, 설정에서 사용 기록을 끄면 됩니다(학습 기능은 그대로 쓸 수 있습니다).

6. 쿠키·광고·분석

서비스는 광고를 표시하지 않으며, 광고·추적 목적의 쿠키나 분석 도구를 사용하지 않습니다. 추후 도입할 경우 이 문서를 먼저 고지합니다.

7. 결제(도입 시)

유료 상품이 도입되면 결제는 결제대행사(PG)를 통해 처리되며, 카드 정보 등 결제 정보는 서비스가 직접 저장하지 않습니다. 도입 시 이 문서에 구체적으로 추가합니다.

8. 만 14세 미만 이용자

만 14세 미만으로 보이는 이용자에게는 로그인을 제공하지 않습니다. 학습·동기화 코드 기능은 이름·연락처 없이 동작합니다.

9. 이용자의 권리

이용자는 언제든 자신의 정보(동기화 데이터·로그인 계정·문의)의 열람·정정·삭제·처리 정지를 요청할 수 있습니다. 앱의 「문의」 버튼이나 아래 연락처로 요청하면 지체 없이 처리합니다.

10. 개인정보 보호책임자·문의

개인정보 관련 문의·삭제 요청: 앱 왼쪽 아래 「문의」 버튼

学習データは基本的にお使いのブラウザ内にのみ保存されます。同期コードまたはログイン（Google・Kakao・LINE、任意）を使った場合のみ、学習データとログイン情報（識別子・メール・名前・プロフィール画像）がクラウド(Supabase、米国)に保存されます。14歳未満と思われる場合はログインを表示しません。単語の意味や例文の検索時には、その単語がMyMemory・Tatoeba・Wiktionaryに送信されます。広告・追跡用のCookieは使用しません。
